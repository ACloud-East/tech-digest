# TechDigest - 科技数码文案聚合网站

一站式聚合科技数码领域热点资讯的平台，涵盖社交媒体热搜和科技媒体资讯。

## 功能特性

- **社交媒体热点看板**：实时聚合微博、抖音、今日头条、百度四大平台热搜
- **科技资讯热点看板**：聚合IT之家、36氪、少数派、爱范儿、虎嗅等10+科技媒体
- **智能内容过滤**：自动筛选AI、手机、芯片、新能源等12个科技领域相关内容
- **AI文案生成**（即将上线）
- **PPT生成**（即将上线）

## 技术栈

- Vue 3 (CDN)
- 纯HTML/CSS/JS
- GitHub Pages 部署

## 本地开发

直接在浏览器中打开 `index.html` 即可。
